# 선박왕 테스트

게임 페이지(`index.html`)와 테스트 봇은 같은 규칙 엔진(`engine.js`)을 씁니다. 그래서 봇이 찾은 문제는 실제 게임의 문제입니다.

| 명령 | 하는 일 | 시간 |
| --- | --- | --- |
| `npm run test:rules` | 규칙 점검 15개 (저장·복원, 매각·출항 제한, 기한 초과, 연료 고갈, 파산, 날씨 등) | 몇 초 |
| `npm test` | 규칙 점검 + 밸런스 백테스트 (시드 20개) | 약 40초 |
| `npm run test:balance` | 밸런스 백테스트 (시드 50개, 봇 5종, 1,000일) | 약 1분 30초 |
| `npm run test:ui` | 브라우저 화면 점검 (Playwright 필요: `npm i -D playwright`) | 약 30초 |

옵션: `node tests/balance.js --seeds 30 --days 1000 --json result.json --report-only`

- `--report-only`: 합격 수치에 실패가 있어도 종료 코드를 0으로 둡니다.
- 3D 라이브러리를 CDN 없이 시험하려면 `THREE_JS=/경로/three.min.js npm run test:ui`.

## 봇 4종 (`bots.js`)

| 성향 | 운영 방식 |
| --- | --- |
| 안전형 | 여유 자금 1.5배를 남기고, 하루 순이익이 확실한 의뢰만, 놀면 계선 |
| 확장형 | 현금이 생기면 바로 증선, 외상 급유도 사용 |
| 전문형 | 모항 주변 반경 안의 항로만 (시대마다 넓어짐) |
| 초보형 | 운임 액수만 보고 고르고, 연료·날씨·빈 배 비용은 무시, 계선 안 함 |

밸런스 백테스트에는 비교용으로 「계선 안 하는 안전형」이 하나 더 돕니다.

## 합격 수치

목표값은 `balance.js` 아래쪽 `checks`에 있고, 기획서 「테스트 계획 > 합격 수치」와 같습니다. 숫자를 바꿀 때는 두 곳을 함께 고칩니다.
