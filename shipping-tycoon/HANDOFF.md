# 선박왕 인수인계 (2026-11-26 기준)

이 문서는 클라우드 세션에서 진행한 작업을, 사용자 PC에서 여는 새 Claude Code 세션이 이어받기 위한 요약입니다.

## 프로젝트와 역할

- 게임: 「선박왕」 해운 경영 RPG. 1955년 한강·낙동강의 똑딱선 한 척으로 시작해, 운송인으로 화물을 날라 운임을 벌고 선단을 키우는 게임.
- Claude Code: 최종 검수자이자 대표(사장). GPT 보고와 Gemini 아이디어를 받아 최종 판단하고 기획서와 게임에 반영한다.
- ChatGPT: 중간 보고를 맡는 프로젝트 담당팀 팀장.
- Gemini: 디자인 등 아이디어를 내는 팀원.
- 공유 폴더: `C:\Users\USER\Desktop\1. Personal Rock\1. 단기 프로젝트\AI 게임_1호_선박왕`

## 지금까지의 주요 결정

1. 상인(화물 매매)이 아니라 운송인(운임)으로 플레이한다. 비용은 연료(유가 변동, 날씨 배율), 고정비, 입항료. 불황에는 계선(휴업).
2. 경영이 뼈대이고 RPG는 층이다. 다음 단계로 선장, 화주 신뢰, 의뢰 4종, 자동 항로, 28일 주기 대형 입찰을 넣는다.
3. 롤백(되돌리기)은 쓰지 않고, 실패는 수리·구조조정으로 복구한다.
4. 아트는 Gemini 시안(청록 바다 위 복셀 섬, 선박 상태 카드)을 기준으로 하되, 코드로 상자를 쌓는 방식으로 만든다.
5. 모든 기능 변경은 밸런스 백테스트(`npm test`)를 통과시키며 진행한다.
